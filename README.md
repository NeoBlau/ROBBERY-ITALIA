# MANO LESTA 🕵️🇮🇹

**Стелс-игра про обаятельного вора в Италии** — в духе Robbery Bob, но масштабнее и глубже:
компактные продуманные уровни, вид сверху, зоны обзора, укрытия, отвлечения, ключи,
взлом, побег и оценка на три звезды.

> _«Un ladro. Cento colpi.»_ — один вор, сто дел.

Играется прямо в браузере (ПК и телефон), **без установки и без сборки** — только статические файлы
и локально подключённый Three.js.

---

## Название (§51)

По ТЗ имя «Robbery Italia» использовать нельзя. Предложено 10 оригинальных вариантов:

`Mano Lesta` · `Colpo Grosso` · `Gattopardo` · `Furbo` · `Notturno` · `Il Gatto` · `Scaltro` · `Bandito` · `Ombra` · `Piano Piano`

Выбрано **MANO LESTA** («ловкая рука» — итальянское выражение о ловком воре: коротко,
стильно, с юмором). Используется во всём интерфейсе.

---

## Как запустить

Нужен любой статический веб-сервер (файлы должны отдаваться по HTTP, не открывайте `index.html` через `file://`).

```bash
# вариант 1 — Python
python3 -m http.server 8099
# вариант 2 — npm
npm run serve
```

Откройте `http://localhost:8099`.

### Деплой на Vercel
Проект — статический сайт. Достаточно подключить репозиторий к Vercel (framework: **Other**,
build command — пусто, output dir — корень). `vercel.json` уже настроен.

## Что реализовано (вертикальный срез, §46–§48)

**5 полностью проходимых уровней в регионе ROMA:**

1. **Casa del Vicino** — квартира. Главная цель: дорогие часы. Патруль хозяина, ключ, укрытие.
2. **Pizzeria da Mario** — ночная пиццерия. Кофемашина. Повар + официант, склад, взлом, задний вход.
3. **La Villa** — вилла. Картина. Хозяин + охранник + **собака**, ключ, несколько маршрутов.
4. **Negozio di Lusso** — бутик. Дизайнерская сумка. **Камеры**, маскировка, продавцы + охрана, выключатель.
5. **Piccolo Museo** — музей. Редкий экспонат. Охрана, камеры, хранилище, тревога и **полиция**.

Каждый уровень: главная цель → дополнительный лут → выход, оценка ★/★★/★★★, деньги, испытания,
сохранение прогресса.

**Работающие системы (§44):**
Player · Camera (вид сверху) · NPC AI (патруль/подозрение/тревога/погоня/поиск/возврат) ·
Detection (конусы обзора + линия видимости + маскировка) · Noise · Loot (авто- и ручной подбор) ·
Inventory (вместимость сумки) · Mission · Doors/Keys/Lockpick (мини-игра) · Hide · Distraction ·
Security Cameras + выключатели · Dogs · Police · Stars · Challenges · Economy · Upgrades (магазин) ·
Costumes · Collections (сувениры) · Save (localStorage) · UI · карта кампании Италии.

## Архитектура (модульная, §44–§45)

```
index.html            — импорт-карта three, canvas, UI-корни
vendor/               — локально подключённый Three.js (r160), без CDN
src/
  main.js             — точка входа
  core/               — Util, Input (клавиатура + сенсор), Save, шина событий
  render/             — Renderer (сцена/свет/камера), Assets (палитра + процедурный реквизит)
  world/              — Level (сборка уровня из данных), Collision (круг↔AABB, линия видимости)
  entities/           — Player, Npc (и собака), SecurityCamera
  systems/            — Detection, Noise, Inventory, Interaction, Scoring
  game/               — Session (рантайм уровня), Game (оркестратор + цикл)
  ui/                 — UI (меню, карта, HUD, пауза, результаты, магазин, коллекция), style.css
  data/               — gamedata (справочники), levels (5 уровней)
```

Уровни — **чистые данные** (`src/data/levels.js`): добавить новый уровень можно, не трогая
логику игры. Это заложено под масштабирование до 100+ уровней и 10 регионов (§49).

## Дорожная карта (§49)

Регион ROMA открыт; FIRENZE, MILANO, VENEZIA, NAPOLI, COSTA AMALFITANA размечены на карте и
открываются по звёздам — контент добавляется данными уровней в том же формате. Дальше: новые типы
NPC, тематический лут по регионам, спецограбления (яхта, гранд-вилла), день/ночь и погода как
модификаторы уровней, больше костюмов и испытаний.
